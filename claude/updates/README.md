# updates/

One file per requested change to something already built:
`updates/<name>.md`, copied from `../templates/update-template.md`.

Use this instead of re-explaining a whole feature when asking the agent to
revise output it already produced — link back to the original
`../features/<name>.md` where relevant.

After the agent's output, a human reviews it, then runs the matching file in
`../tests/`.
